/start
  Non-member  → Plain rejection (no join link — closed system)
  Member      → Welcome message [ဆက်လုပ်ရန်] button

[ဆက်လုပ်ရန်]
  → Ask Student ID (e.g. G9A001, normalized to uppercase alphanumeric)

Student types ID
  → Show class buttons (from Payment Accounts sheet)

Student picks class
  → Show [WavePay] [NUGPay] buttons

Student picks method
  → Show account details (name + number/NUG ID)
  → Ask amount (Ks)

Student types amount
  → Ask to send Screenshot

Student sends photo
  → Gemini Vision extracts: status, entered_amount(SS), from_account,
      to_account, transaction_id, date_time
  → Check: status == Success
  → Check: not duplicate transaction ID
  → Check: to_account matches expected account (soft check)
  → Upload to Drive: DonatingBot Screenshots / 2026 August / filename.jpg
  → Save to Sheets: 13 columns including BOTH amounts
  → Send Burmese thank-you card
